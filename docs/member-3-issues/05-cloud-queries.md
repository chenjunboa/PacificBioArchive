# [MEMBER 3] 完成四类云端查询与临时文件清理

## 当前缺口

第二阶段只保证登录、上传和最小状态链路；标签数量、物种、缩略图和上传文件查询尚未在完整
云端索引上验收。

## 要求

- 多标签最低数量使用各 TAG 索引结果交集，禁止 Scan；
- 物种查询复用相同索引和标签标准化；
- 缩略图查询通过稳定 URL hash 读取 THUMB 映射；
- 临时文件上传到 `temporary-queries/{queryId}/...`，识别后执行全部正数量标签 AND 查询；
- 临时查询不得创建 MEDIA/checksum；成功、识别失败和查询失败都立即删除临时对象；
- S3 一天生命周期仅作兜底。

## 验收

- 自动测试覆盖全部四类查询、空结果和非法输入；
- 成功与失败后都证明临时对象已删除；
- 真实云端证据证明查询不依赖表扫描和持久预签名 URL。
