# [MEMBER 3] 补齐云端故障注入、媒体边界和验收证据

## 当前缺口

第二阶段证明一张真实 JPG 的正常链路，但尚未覆盖所有媒体边界、错误恢复和评分所需的完整
云端证据。

## 要求

- 横图、竖图、透明 PNG 缩略图保持比例且最长边不超过 480；
- 2.4 秒视频严格抽取 3 帧，物种数量取各帧最大值而非求和；
- 坏视频进入明确 `FAILED`；
- 注入 GCP 超时、S3/DynamoDB 短暂失败和重复 SQS 事件；
- 验证重试、DLQ、幂等与用户可操作错误；
- 日志不得泄露 token、预签名 URL 或内部凭据。

## 验收

- 自动测试覆盖上述所有场景；
- 真实云端提供一张图片和一个短视频、46 类维度、模型版本、CloudWatch、DynamoDB 前后状态和
  DLQ 的脱敏证据；
- 每项证据标记 UTC 时间和测试 commit。
