# [MEMBER 3] 完成标签、SNS 订阅、所有者授权和一致性删除

## 当前缺口

第二阶段创建 SNS topic 和最小 API 边界，但完整订阅确认、标签通知、所有者限制和跨资源删除
尚未验收。

## 要求

- 批量标签 operation 1 添加、0 删除；删除不存在标签保持成功；
- 标签变化同步维护索引，只有实际新增或数量更新的匹配标签触发通知；
- SNS 邮箱只有确认后才视为有效订阅；
- 只有 owner 可以修改标签或删除，其他认证用户可查询；
- 删除先标记 `DELETING`，再清理原文件、缩略图、索引、映射、checksum 锁和媒体记录；
- 重复删除幂等。

## 验收

- 覆盖订阅/取消、确认前不通知、匹配通知和重复操作；
- 非 owner 修改和删除返回 403；
- 删除后 S3 与 DynamoDB 所有关联项均消失。
