# [MEMBER 3] 完成 Worker 幂等租约、重试、DLQ 和失败状态

## 当前缺口

第二阶段 Worker 已能由 SQS 触发并通过 WIF 调用真实 inference，但并发消息租约、完整重试和
最终失败语义尚未完成。

## 要求

- 用条件更新取得 `PROCESSING` 租约，防止重复消息并发处理；
- 已完成消息重复投递时保持幂等；
- 可重试错误抛回 SQS，达到次数后进入 DLQ；
- 最终失败将媒体标为 `FAILED` 并保存可操作、无敏感信息的错误；
- 成功路径原子更新模型版本、标签、索引、缩略图映射和 `READY` 状态。

## 验收

- 测试重复消息、并发 Worker、租约超时接管、GCP 超时和 AWS 短暂失败；
- 证明成功消息只产生一次最终结果；
- 提供脱敏 CloudWatch、SQS/DLQ 和状态变化证据。
