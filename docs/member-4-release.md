# 第四位成员执行手册：React、端到端测试和最终发布

## 你的目标

把第三位成员完成的云端 API 整合成可连续演示、错误信息清楚、无需手工改数据库的最终系统，
并组织最终验收证据。

开始标签：`handoff-3-core-complete`  
工作分支：`member-4/ui-e2e`  
完成标签：`release-candidate-1`

## 第一步：接受后端交接

```powershell
git fetch --tags origin
```

先用 API 完成一次登录、上传、四类查询、标签和删除。如果后端功能失败，建立 Issue 交回第三位
成员，不要在前端伪造成功结果。

## 第二步：完成 Cognito/Amplify 登录页面

页面必须包含：

- given name、family name、email、password 注册；
- 邮箱验证码确认；
- 登录、会话恢复、token 刷新、退出；
- 验证码错误、密码不符合要求、用户不存在和网络失败提示；
- 本地模式继续使用开发 JWT，云端构建中不能出现开发登录入口。

Cognito 配置从 Vite 环境变量读取，不把测试用户、密码或 token 写入代码。

## 第三步：完成上传体验

1. 文件选择器只接受 JPG/JPEG/PNG/MP4/MOV。
2. 页面显示图片 20 MB、视频 100 MB/60 秒限制。
3. 浏览器计算 SHA-256 时显示“正在计算校验值”。
4. 显示上传进度或至少明确的上传中状态。
5. 上传后轮询媒体状态，依次显示 RESERVED/UPLOADED/PROCESSING/READY/FAILED。
6. 409 显示“文件内容已存在”并提供已有媒体 ID，而不是普通未知错误。
7. FAILED 显示后端安全错误和重试建议。
8. 图片显示缩略图；视频提供可用的临时播放/下载地址。

## 第四步：完成四类查询页面

### 标签数量查询

允许添加多行“标签 + 最低数量”，请求使用 AND。数量必须是大于等于 1 的整数。

### 物种查询

从 `/species` 的 46 项中选择，不允许前端维护另一份写死的物种列表。

### 缩略图反查

用户输入缩略图 URL，结果显示正确原图链接和 mediaId。过期或无效 URL 显示明确错误。

### 上传文件查询

显示临时文件上传和识别状态，结果与普通查询使用同一媒体卡片。页面不能把临时文件显示成新媒体。

所有查询都要有：加载状态、无结果状态、失败状态和清空/重新查询操作。

## 第五步：完成媒体管理和通知

- 媒体卡显示类型、状态、标签数量、模型版本、创建时间。
- owner 才能看到增加标签、删除标签和删除媒体按钮。
- 删除前二次确认，成功后立即从当前列表清除。
- 标签支持批量选择多个 URL；operation 1/0 的含义在 UI 中写成人类可读文字。
- 订阅和取消订阅都有成功/失败提示，并说明 SNS 邮件需要用户点击确认。
- 即使前端隐藏按钮，也要用手工请求验证其他用户仍收到 403。

## 第六步：错误和界面要求

至少为以下情况提供单独信息：

- 401：登录失效，请重新登录；
- 403：没有修改该媒体的权限；
- 409：相同内容已经上传；
- 413：文件超过大小限制；
- 422：文件类型、checksum 或请求字段错误；
- FAILED：媒体处理或模型调用失败；
- 网络/Cloud Run 冷启动：显示等待或重试，不显示空白页。

演示分辨率下按钮和结果不能遮挡；页面操作期间浏览器控制台不能出现错误。

## 第七步：编写 Playwright 测试

本地完整测试至少覆盖：

1. 登录。
2. 上传图片并等待 READY。
3. 重复上传显示 409。
4. 标签数量查询找到图片。
5. 缩略图反查。
6. 增加和删除标签。
7. 非 owner 无权修改。
8. 删除媒体并确认不再出现。
9. 退出后业务请求被拒绝。

云端冒烟测试覆盖注册/验证后登录、真实上传、至少两类查询和删除。验证码不应硬编码进入 CI；
需要人工邮箱的步骤可以作为受控预备步骤，后续使用专用已验证测试用户。

关键云端流程必须连续运行两次成功，并保存 Playwright 报告或视频。

## 第八步：准备演示脚本

在你的 PR 中增加 `docs/demo-script.md`，逐分钟写：

1. 谁登录、使用哪个预先验证的测试用户。
2. 上传哪张图片和哪个短视频。
3. 每一步点击位置、输入内容和预期结果。

5. 演示用文件的 checksum 和备用文件。
6. Cloud Run 冷启动时的等待话术和失败备用方案。
7. 演示后哪些临时媒体需要清理。

Demo 前预热 Cloud Run，但不能手工修改数据库来制造结果。
