# Official icon sources

The architecture diagram uses only official cloud-provider product icons:

- AWS Architecture Icons, icon package released 31 July 2026:
  https://aws.amazon.com/architecture/icons/
- Google Cloud product icon library, current core product icons and official legacy icons:
  https://cloud.google.com/icons

AWS icons used: Amazon Cognito, Amazon API Gateway, AWS Lambda, Amazon S3, Amazon SQS,
Amazon DynamoDB, Amazon SNS, and Amazon ECR.

Google Cloud icons used: Cloud Run, Cloud Storage, Artifact Registry, and Workload Identity Pool.

The browser and email recipient shapes are neutral diagram primitives, not cloud service icons.
